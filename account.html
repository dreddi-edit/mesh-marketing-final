First launch? macOS may show "Mesh IDE is damaged" — that's Gatekeeper rejecting unsigned downloads. One-line fix:

Run this in Terminal, once. Removes the com.apple.quarantine attribute Chrome/Safari added during download:

xattr -cr "/Applications/Mesh IDE.app"

After that, double-click Mesh IDE in Programme normally. Notarized builds are coming once we register with the Apple Developer Program.

    05 — Security

    Account access

    supabase auth

    Reset password

    We email a one-time link to your account address. Works for both password and OAuth accounts (sets a password you can use as a fallback).

    Sign out everywhere

    Revokes every active Supabase session — including the CLI's stored token. Next mesh run will prompt a fresh login.

    Delete account

    Permanent. Removes your profile, plan, and all stored sessions. We can't recover this.
